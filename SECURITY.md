# Security Policy · 安全说明

This repository contains Markdown instructions and one small shell script (`scripts/check_references_sync.sh`); it has no runtime service and collects no data.
本仓库只有 Markdown 说明和一个小的 shell 脚本，没有运行时服务，也不收集数据。

If you find a security problem (for example, an unsafe command in an install note or script), please do **not** open a public issue with details. Email [xingtaxueshu@outlook.com](mailto:xingtaxueshu@outlook.com) with the subject "Security" and a short description; we will reply as soon as we can.
如果发现安全问题（例如安装说明或脚本里有不安全的命令），请不要在公开 Issue 里写细节，发邮件到 xingtaxueshu@outlook.com，主题写 “Security”，简要说明即可，我们会尽快回复。

Please also do not paste unpublished manuscripts or personal data into issues.
也请不要在 Issue 中粘贴未发表稿件或个人信息。
