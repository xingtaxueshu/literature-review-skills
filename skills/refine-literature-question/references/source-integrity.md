# 来源完整性规则（Source Integrity）

适用范围：本仓库的根 `SKILL.md` 与 5 个 skill。版本 0.2.0。

文献综述里最容易出事的不是结构，而是来源：AI 可能给出看起来很像真的作者、年份、期刊、页码，甚至整篇不存在的文献。这份规则把“只用有来源的东西”变成每一步都要遵守的流程。它是流程约束，不是保证；最终核验责任在研究者。

## 一、核心规则

1. **只使用用户提供或已核验的文献。** 用户没给、也没核验过的文献，不得作为论据、示例或“已有研究表明”的依据。
2. **每条文献带状态标签**：`用户提供` / `已核验` / `未核验`（定义见下表）。
3. **查不到一律写“未查到”。** 不得补全或猜测作者、年份、期刊、卷期、页码、DOI。哪怕“记得大概是”也不行。
4. **不编造研究发现。** 涉及“已有研究发现 X”的句子，要么能对应到一条带标签的文献，要么标 `[需补来源]`。方法演示用的假设性例子必须明说是“示例/假设”。
5. **没搜过不等于没有研究。** 不能因为自己（或 AI）没找到，就断言“少有研究”或“存在空白”；证据不足时写“需核实”。
6. **题录疑点只标记，不替改。** 用户给的题录若看着不对（年份与期刊对不上、作者拼写可疑等），在“待核实清单”里指出，不要悄悄改成“正确版本”。

## 二、状态标签

| 标签 | 含义 | 能否作为论据 |
|---|---|---|
| 用户提供 | 用户在对话中给出了这条文献（题录、摘要、笔记或全文），AI 只按用户给的内容使用，**没有**独立核对题录是否真实。 | 可以，但要说明“按用户提供的信息”，并建议用户自行核对。 |
| 已核验 | 已用下面的核验步骤查证，题录（至少题名、作者、年份、出处）一致，且**记录了核验方式**。 | 可以。注意：已核验通常只表示“这篇文献存在且题录对得上”，不表示它的结论被读过或被正确概括，见第三节。 |
| 未核验 | 只有线索（只有题名/作者名、AI 回忆出的候选、核验未完成或不一致）。 | 不可以。只能列入“待核实清单”。 |

“未查到”是核验**结果**，不是第四种标签：核验过但查不到，标签仍为 `未核验`，结果写“未查到”。

## 三、核验步骤

1. **原样记录**用户提供的题录，不先做任何“修正”。
2. **有 DOI**：
   - Crossref：`https://api.crossref.org/works/<DOI>`
   - OpenAlex：`https://api.openalex.org/works/doi:<DOI>`
   - 比对题名、作者、年份、期刊/出版物名称。
3. **没有 DOI**：用“题名 + 第一作者”在 Crossref（`query.bibliographic`）或 OpenAlex 检索；英文图书可再查出版社或图书馆目录。
4. **出版社 / 期刊官网页面**：作为补充核对，尤其是 Crossref 与 OpenAlex 都查不到时。
5. **中文文献（CNKI / 万方 / 维普）**：这些库通常需要账号权限，AI 往往无法直接检索。请用户在自己有权限的账号里人工检索，把查到的题录或截图文字反馈回来；AI 只记录“用户人工检索反馈”，不得自行补全。
6. **区分核验范围**：
   - 题录核验：这篇文献存在，题录一致。
   - 摘要/全文核对：它是否真的支持被引用的那个结论。需要读过摘要或全文才能说，没读过就写“结论未核对”。
7. **记录核验方式与日期**，例如：`Crossref 按 DOI 查询，核验日期 <实际日期>，题名/作者/年份一致，结论未核对`。不要写没有真的做过的核验。
8. **结果处理**：
   - 完全一致 → `已核验`。
   - 部分不一致 → 保持 `未核验`，写出差异，交用户裁决。
   - 查不到 → 保持 `未核验`，结果写“未查到”。查不到也不代表一定不存在（见第五节）。
9. **没有联网或检索工具时**：不假装核验。全部按 `用户提供` 或 `未核验` 标注，并把第 2–5 步列给用户自己做。

## 四、在输出里怎么呈现

- 每个涉及文献的表格或段落，要有“出处 / 核验状态”信息：`作者（年份）· 状态标签 · 核验方式`。作者、年份只写用户提供或核验到的。
- 用户没有提供任何文献时，如实说明“本次未提供文献，以下为方法框架，不含文献结论”，不要用想象的文献填表。
- 每个 skill 的输出末尾固定有“待核实清单”和“给作者的问题”，格式见 [output-contract.md](output-contract.md)。
- 自动生成的段落一律叫“段落草稿（需作者改写并核对来源）”，其中依赖文献的句子要带来源标签或 `[需补来源]`。

## 五、这份规则做不到的事

- 它不能保证模型一定照做；请研究者抽查输出里的每条文献。
- Crossref、OpenAlex 对中文文献、部分图书和灰色文献覆盖不全。查不到不等于不存在，也不等于存在。
- 本规则目前没有经过系统评测，也没有真实作者的使用反馈。
- 它没有提供中文文献专门流程，只给了人工检索的提示。
